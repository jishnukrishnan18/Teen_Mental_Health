# Teen_Mental_Health
Teen Mental Health Analysis using Machine Learning

This project analyzes teen mental health factors such as social media usage, screen time, sleep hours, stress levels, academic performance, and lifestyle habits using Machine Learning techniques. The project includes data preprocessing, Exploratory Data Analysis (EDA), visualization, and predictive modeling to identify patterns affecting mental well-being among teenagers.

Technologies Used:

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

Features:

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Data Visualization
* Classification & Prediction Models
* Mental Health Pattern Analysis

Goal:
To understand how digital habits and lifestyle factors influence teen mental health and build predictive models for analysis.
